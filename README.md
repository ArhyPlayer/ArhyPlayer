# ArhyPlayer // Vibe Coder

> "Fast prototyping, clean execution, agentic mindset."

### 🔧 Специализация
* **AI-Agents:** Создаю автономных агентов, которые не просто отвечают на вопросы, а решают конкретные бизнес-задачи.
* **Memory:** Внедряю долгосрочную память (RAG) для LLM, позволяя ботам учитывать историю и контекст каждого клиента.
* **API First:** Проектирую чистые, документированные и масштабируемые API для бесшовной интеграции сервисов.

---

### 📦 Инструментарий
* **Core:** Python 3.10+, Flask, FastAPI, REST, Webhooks.
* **AI:** OpenAI API, LangChain, MCP (Model Context Protocol).
* **DB & Infra:** PostgreSQL, ChromaDB (Vector Search), Docker.
* **Interface:** Aiogram 3 (Telegram Bot API), Web Apps.

### 🏁 Проекты
* **[CLI_PDF_Generator](https://github.com/ArhyPlayer/CLI_PDF_Generator.git)** — CLI Генератор PDF документов из CSV/JSON данных и HTML шаблонов с поддержкой кириллицы.
* **[AI_PDF_Generarator](https://github.com/ArhyPlayer/AI_PDF_Generarator.git)** — Инструмент автоматизации отчетности. Анализирует диалоги с клиентами и мгновенно формирует структурированные PDF-документы.
* **[TG_API_Weather](https://github.com/ArhyPlayer/TG_API_Weather.git)** — Полнофункциональное погодное приложение с CLI и Telegram Bot интерфейсами.
* **[TG_API_Exchanger](https://github.com/ArhyPlayer/TG_API_Exchanger.git)** — Telegram-бот для управления расходами в путешествиях с автоматической конвертацией валют через API exchangerate.host.
* **[TG_Idea_Saver](https://github.com/ArhyPlayer/TG_Idea_Saver.git)** — Мощный Telegram-бот для совместного управления задачами в команде.
* **[TG_AI_Assistant](https://github.com/ArhyPlayer/TG_AI_Assistant.git)** — Telegram-бот на Python с поддержкой OpenAI GPT-3.5-turbo и Anthropic Claude Sonnet 4.5 для интеллектуальных диалогов с сохранением контекста каждого пользователя.
* **[AI-Agent](https://github.com/ArhyPlayer/AI-Agent.git)** — Продвинутый Telegram-бот с искусственным интеллектом. Поддержка мультимодальности: генерация текста, изображений и видео через OpenAI.
* **[Pine_BOT](https://github.com/ArhyPlayer/Pine_BOT.git)** — Умный ассистент с долговременной памятью на базе Pinecone, Haystack и OpenAI.
* **[Bronirovanie.db](https://github.com/ArhyPlayer/Bronirovanie.db.git)** — Система управления бронированием для ресторанного бизнеса. Реализована на Python с использованием PostgreSQL для надежного хранения данных.
* **[Loki-Grafana](https://github.com/ArhyPlayer/Loki-Grafana.git)** — Проект для отправки логов в Grafana Loki с использованием Python. Включает FastAPI бэкенд, фронтенд на nginx и эмулятор криптовалютного приложения.
* **[MiniCRM](https://github.com/ArhyPlayer/MiniCRM.git)** — Десктопная CRM-система с FastAPI-бэкендом, Tkinter-интерфейсом и интеграцией Google Drive / Google Sheets для экспорта отчётов.
* **[Auto-Web](https://github.com/ArhyPlayer/Auto-Web.git)** — Docker-инфраструктура для web-сервиса сбора лид-заявок.
Все данные обрабатываются и хранятся строго внутри контура сервера.
